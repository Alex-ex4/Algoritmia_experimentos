# Algoritmia DOE

Repositorio correspondiente a la práctica de optimización heurística, enfocada en el ajuste del parámetro de temperatura inicial (T0) para el **Recocido Simulado con operador 2-opt aplicado al Problema del Vendedor Viajero (TSP)**, utilizando la **Metodología de Superficie de Respuesta (RSM)** para evaluar instancias de n en {5, 10, 15} ciudades.

    ├── README.md                   # Estructura del repositorio.
    ├── tarea3_rsm.py               # Script auto-contenido del experimento RSM y Recocido Simulado
    ├── LASS_REPORTE.AyO            # Reporte con tabla resumen y analisis
    └── graphics/
      └── rsm_curvas_ajustadas.png  # Curvas cuadráticas ajustadas con IC 95% para n = 5, 10, 15
